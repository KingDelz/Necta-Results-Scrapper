# NECTA Results Scraper (CSEE & ACSEE)

An R-based web scraping tool for collecting NECTA examination results for both  
**CSEE (Form Four)** and **ACSEE (Advanced Level)** directly from the official NECTA website and exporting them into a clean, analysis-ready Excel file.

---

## 📌 Overview

This project automates the extraction of division-level examination results from the NECTA online results portal. Given a list of school examination center numbers, the script:

- Scrapes results for multiple schools and years
- Supports both CSEE and ACSEE
- Handles missing or unavailable result pages
- Cleans and reshapes HTML tables into tidy data
- Exports a consolidated Excel dataset

---

## 🔍 Data Source

- Official NECTA results portal:  
  [https://onlinesys.necta.go.tz/results/](https://onlinesys.necta.go.tz/results/)

## ✨ Features

- ✅ Scrapes CSEE (Form Four) and ACSEE (Advanced Level) results
- 📅 Supports multiple examination years
- 🏫 Processes hundreds of schools automatically
- 🧹 Cleans and standardizes scraped tables
- 📊 Outputs tidy, long-format data
- 📁 Exports results to Excel
